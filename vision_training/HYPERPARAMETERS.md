# YOLO 학습 하이퍼파라미터 선정 근거

## 1차 학습 (`yolo_train.py`)

목적은 동일한 데이터와 조건에서 YOLOv8, YOLO11, YOLO26의 n/s 모델을
공정하게 비교하고, 고정 웹캠 영상의 작은 목각인형과 RC카를 탐지하는 기본
모델을 만드는 것이다.

| 항목 | 설정 | 선정 이유 |
|---|---:|---|
| 초기 가중치 | COCO 사전학습 `.pt` | 처음부터 학습하는 것보다 일반적인 윤곽·질감 특징을 재사용해 적은 데이터에서도 빠르게 수렴한다. |
| `epochs` | 100 | 데이터가 작아 충분한 반복 학습 기회를 주되, 실제 종료 시점은 early stopping이 결정하도록 최대값을 넉넉하게 설정했다. |
| `patience` | 20 | 일시적인 검증 지표 정체 때문에 너무 빨리 종료되는 것을 방지하면서 과적합 이후의 불필요한 학습을 줄인다. |
| `imgsz` | 640 | 원본이 640×480이고 탐지 대상이 작다. YOLO 표준 입력 크기이면서 작은 객체 정보와 GPU 사용량 사이의 균형이 좋다. |
| `batch` | 8 | 약 6GB GPU에서 멀티스케일 입력이 최대 약 800px까지 커지는 상황을 고려한 안정적인 크기다. |
| `workers` | 8 | 이미지 로딩과 증강을 병렬 처리해 GPU 대기 시간을 줄인다. 시스템에 따라 낮출 수 있다. |
| `scale` | 1.0 | 고정 카메라에서도 인형과 RC카의 거리·화면 내 크기가 달라지므로 강한 크기 변화를 학습해 위치·크기 일반화를 유도한다. |
| `multi_scale` | 0.25 | 배치별 입력을 기준 크기 640의 ±25% 범위로 바꿔 작은 객체와 다양한 거리 변화에 대한 강건성을 높인다. |
| `amp` | 활성화 | FP16 혼합정밀로 GPU 메모리 사용량과 학습 시간을 줄이면서 일반적으로 정확도 손실을 최소화한다. |
| `seed` | 42 | 데이터 순서와 학습의 무작위성을 고정해 모델 비교의 재현성을 높인다. |
| `deterministic` | 활성화 | 같은 설정의 반복 실행 결과 차이를 줄여 6개 모델 비교를 공정하게 만든다. |
| `plots` | 활성화 | loss, confusion matrix, PR/F1 곡선과 예측 샘플을 남겨 수치뿐 아니라 학습 상태를 검토한다. |
| 최종 비교 split | `val` | 학습 중 모델 선택과 6개 모델 비교에는 검증 데이터를 사용하고, test 데이터는 최종 일반화 확인용으로 남긴다. |

모델마다 동일한 하이퍼파라미터를 적용한 이유는 특정 모델에 유리한 조건을
주지 않고 구조 자체의 정확도와 속도를 비교하기 위해서다. 학습률과 optimizer
등 명시하지 않은 항목은 설치된 Ultralytics 버전의 기본/자동 설정을 사용한다.

## Hard negative 파인튜닝 (`yolo_finetune.py`)

목적은 1차 모델의 `fallen_person`·`helper_rc_car` 탐지 성능을 유지하면서,
서 있는 인형과 빈 공간을 `fallen_person`으로 잘못 탐지하는 문제를 줄이는
것이다. 따라서 기존 양성 907장과 빈 라벨 hard negative 104장을 함께 쓴다.

| 항목 | 설정 | 선정 이유 |
|---|---:|---|
| 초기 가중치 | 1차 학습 `best.pt` | 이미 학습한 두 클래스의 특징을 유지한 상태에서 자세 구분만 보완한다. |
| 데이터 | 양성 907장 + 음성 104장 | 음성 데이터만 학습할 때 기존 탐지 능력을 잊는 catastrophic forgetting을 방지한다. |
| `epochs` | 25 | 새로운 클래스 학습이 아니라 오탐 보정이므로 1차 학습보다 짧게 설정해 과도한 가중치 변화를 막는다. |
| `lr0` | 0.0001 | 낮은 학습률로 기존 가중치를 급격히 훼손하지 않고 서기·빈 공간에 대한 판단 경계만 점진적으로 조정한다. |
| `patience` | 10 | 최대 25 epoch의 짧은 학습에 맞춰, 개선이 없을 때 빠르게 종료하도록 1차 학습보다 줄였다. |
| `imgsz` | 640 | 1차 학습 및 실제 웹캠 입력과 동일하게 유지해 입력 분포 변화를 방지한다. |
| `batch` | 8 | 1차 학습과 같은 메모리 조건을 유지하고 양성·음성 샘플을 한 배치에서 안정적으로 학습한다. |
| `workers` | 8 | 데이터 로딩 병목을 줄인다. |
| `seed` | 42 | 파인튜닝 결과를 재현하고 전후 비교를 쉽게 한다. |
| `deterministic` | 활성화 | 실행 간 무작위 차이를 줄인다. |
| `close_mosaic` | 마지막 5 epoch | 마지막 구간에는 합성 mosaic를 끄고 실제 웹캠 한 장의 분포로 학습을 마무리해 자세·배경 판단을 안정화한다. |
| 최종 평가 split | `test` | 학습과 모델 선택에 직접 쓰지 않은 별도 데이터에서 파인튜닝 효과와 오탐 감소를 확인한다. |

전체 layer를 업데이트하되 학습률과 epoch를 낮게 둔다. 자세 구분은 최종
분류 head뿐 아니라 형상과 배경 특징에도 영향을 받을 수 있어 layer를 완전히
동결하지 않았고, 대신 작은 학습률로 기존 특징을 보호한다.

## 발표용 요약

> 1차 학습은 6개 YOLO 모델을 같은 조건에서 공정하게 비교하기 위해 최대
> 100 epoch, 640 입력, batch 8을 사용했고, 고정 카메라의 작은 객체와 거리
> 변화에 대응하기 위해 scale 및 multi-scale 증강을 적용했다. 파인튜닝은
> 이미 높은 양성 탐지 성능을 보존하면서 서 있는 인형과 빈 공간의 오탐만
> 줄이는 단계이므로 기존 양성 데이터와 hard negative를 함께 사용하고,
> 학습률을 0.0001로 낮추고 25 epoch로 짧게 설정했다.

## 주의사항

- 높은 val 성능만으로 서기·눕기 구분 성능을 판단할 수 없다. hard negative가
  포함된 test와 실제 웹캠 영상에서 반드시 확인한다.
- `inference_fps`는 모델 추론 시간 기준이며 전처리·후처리·카메라 I/O를 포함한
  실제 시스템 FPS와 다를 수 있다.
- GPU 메모리 부족 시 `batch`를 4로 낮출 수 있다. 이는 모델 목적의 변경이
  아니라 하드웨어 제약에 대한 조정이다.
