# 최종 보정 후 ETA 예측 정확도 실측 보고서

## 1. 분석 범위

이 문서는 최종 ETA 계산식과 보정값을 코드에 적용한 **이후**의 정상 도착
주행만 분석한다. 계산식 결정에 사용한 초기 보정 8회와 그 데이터를 현재
공식으로 사후 재계산한 값은 포함하지 않았다.

포함 조건은 다음과 같다.

- 중앙 mission manager가 최종 계산식으로 예측 ETA를 기록함
- 동일한 요청에서 실제 Action 주행시간을 기록함
- Nav2가 최종 `ARRIVED`로 정상 종료됨

경로 생성 실패, `no path progress`, 코너 접촉 후 강제 종료, Action 취소
주행은 제외했다.

|---|---:|---:|---:|---:|

| BLOCKED keepout 주행 | 5회 | 2.25초 | 8.68% | 10.23% |
| **전체** | **9회** | **1.61초** | **7.02%** | **8.38%** |

최종 보정 후 유효 실주행의 평균 오차율은 약 7%, 실제시간 가중 오차율은
약 8%다. 프로젝트 설명에서는 환경 변화와 표본 수를 고려해 **약 ±10%**,
보수적으로는 **±15% 이내**로 표현하는 것이 적절하다.

일반 통합 주행은 MAPE 4.94%, BLOCKED 우회 주행은 8.68%였다. 사람 없이
혼잡 토픽과 코드만 확인한 CROWDED 테스트는 실제 혼잡 주행이 아니므로
이 통계에서 제외했다.

## 3. 오차 계산 기준

```text
시간 오차 = 실제 도착시간 - 예측 ETA
절대 오차율 = |실제 도착시간 - 예측 ETA| / 실제 도착시간 × 100
```

- 시간 오차가 양수이면 예측보다 늦게 도착했다.
- 시간 오차가 음수이면 예측보다 빨리 도착했다.
- MAPE는 각 주행의 절대 오차율을 동일한 비중으로 평균한 값이다.
- 실제시간 가중 오차율은 `전체 절대오차 합 / 전체 실제시간 합`이다.

## 6. 조건별 해석

### 일반 통합 주행

두 로봇을 모두 후보로 두고 Nav2 경로를 비교한 뒤 선택된 로봇만 출동했다.
4회 모두 정상 도착했으며 MAPE는 4.94%였다. 기본 거리·회전·코너 ETA
모델은 정상 통신 상태에서 충분한 정확도를 보였다.

### BLOCKED keepout 주행

BLOCKED 구역을 경로에서 제외한 뒤 우회 경로를 계산한 정상 도착 5회다.
모든 선택 경로의 ROI 통과 거리는 0m였고 별도 혼잡 지연은 없었다.
MAPE는 8.68%로, 우회로의 거리와 회전량을 이용한 ETA 계산은 비교적
안정적이었다.

## 7. 현재 ETA 계산식

```text
기본 ETA = 경로 거리 / 기준 선속도
         + 내부 누적 회전량 / 기준 각속도
         + 큰 내부 코너 개수 × 코너 페널티

최종 ETA = 기본 ETA + 혼잡구간 추가 지연
```

| 파라미터 | 현재 값 |
|---|---:|
| 기준 선속도 | 0.20m/s |
| 기준 각속도 | 0.70rad/s |
| 큰 내부 코너 페널티 | 4.0초/회 |
| 경로 단순화 허용오차 | 0.10m |

## 8. 발표용 결론

> 최종 보정 후 두 로봇의 유효 정상 도착 주행 9회를 분석한 결과, ETA의
> 평균 절대 백분율 오차는 7.02%, 실제시간 가중 오차율은 8.38%였다.
> 일반 주행의 MAPE는 4.94%, BLOCKED 우회 주행은 8.68%였다. 프로젝트
> 대표 오차는 약 ±10%, 보수적으로는 ±15% 이내로 표현한다.


## 10. 제외 데이터

다음 데이터는 ETA 정확도 통계에 포함하지 않았다.

- 최종 보정 이전의 주행 및 사후 재계산 데이터
- 실제 사람 없이 토픽과 로직만 확인한 CROWDED 코드 테스트
- Nav2 경로 생성 실패
- `no path progress`로 종료된 주행
- 물리적 코너 접촉 후 사용자가 강제 종료한 주행
- 중복 mission executor가 동일 목표를 선점한 주행
- 통신 단절로 Action 결과를 받지 못한 주행

실패 데이터는 ETA 오차가 아니라 주행 성공률과 신뢰도 지표로 별도
집계하는 것이 적절하다.

## 12. RPP 적용 후 짧은 왕복 추가 검증

2026-08-07에 Robot2의 컨트롤러를 Regulated Pure Pursuit로 변경한 뒤,
현재 위치 주변의 짧은 경로를 왕복하며 2회 추가 측정했다. 두 회차 모두
Nav2 Action은 정상 도착했다.

| 회차 | 경로 | 거리 | 회전량 | 감속 횟수 | 예측 ETA | 실제시간 | 오차 | 절대 오차율 | 결과 |
|---:|---|---:|---:|---:|---:|---:|---:|---:|---|
| 1 | `(0.08, 0.07)` → `(0.10, 0.70)` | 0.72m | 269.0° | 1 | 14.28초 | 25.46초 | +11.18초 | 43.91% | ARRIVED |
| 2 | `(0.10, 0.70)` → `(0.08, 0.07)` | 0.53m | 215.0° | 0 | 8.02초 | 12.15초 | +4.13초 | 34.00% | ARRIVED |

이번 두 경로의 MAPE는 38.96%, 실제시간 가중 오차율은 40.71%다.
경로가 1m보다 짧아 고정적인 초기 회전·가감속·목표 접근 시간이 전체
주행시간에서 차지하는 비율이 컸다. 따라서 이 데이터는 기존 장거리 ETA
정확도 통계 9회에는 합치지 않고, 짧은 출동 경로용 고정 지연항을 추가로
보정할 필요가 있다는 근거로 별도 기록한다.

## 13. RPP 적용 후 장거리 추가 검증

짧은 경로의 큰 오차가 거리 특성 때문인지 확인하기 위해 Robot2를
`(0.20, 0.15)` 부근에서 `(2.50, 2.50)`까지 주행시켰다. 목표 전송 전에
ComputePathToPose 성공을 확인했으며 Nav2 Action도 정상 도착했다.

| 경로 거리 | 회전량 | 감속 횟수 | 예측 ETA | 실제시간 | 오차 | 절대 오차율 | 결과 |
|---:|---:|---:|---:|---:|---:|---:|---|
| 3.35m | 111.1° | 0 | 19.50초 | 20.55초 | +1.06초 | 5.16% | ARRIVED |

3.35m 장거리에서는 오차율이 5.16%로 기존 정상 주행 범위와 비슷했다.
따라서 1m 미만 경로의 34~44% 오차는 모델 전체의 불량이라기보다 초기
회전·가감속·목표 접근 시간의 비중이 커지는 짧은 경로 문제로 판단한다.
